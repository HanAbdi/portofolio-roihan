Gizi Sehat Web Application

A web-based application designed to calculate daily nutritional needs and manage user data efficiently.

Built as part of an academic project focused on health-related solutions

Problem

Many people find it difficult to calculate their daily nutritional needs accurately. Existing solutions are often not user-friendly or lack personalized data handling.

Solution

I developed a web application using CodeIgniter 4 and MySQL to provide a simple and efficient system for calculating daily nutritional needs and managing user data.

Tech Stack

CodeIgniter 4 MySQL HTML CSS

Key Features

  • • Daily nutritional needs calculation based on user input
  • • User data management with CRUD functionality
  • • Structured database design using MySQL
  • • Clean and responsive web interface

Result

This project enhanced my understanding of data processing, database design, and backend logic implementation. It also improved my ability to build structured web applications using the MVC architecture.
