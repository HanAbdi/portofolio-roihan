F1Tracker Mobile App

A mobile application that provides real-time Formula 1 race information with a clean and user-friendly interface.

Problem

Formula 1 fans often struggle to access up-to-date race information in a simple and mobile-friendly format. Existing platforms tend to be cluttered or not optimized for quick access.

Solution

I developed a mobile application using Flutter and Firebase to deliver real-time race data with a clean interface, making it easier for users to track schedules, results, and standings.

Tech Stack

Flutter Firebase

Key Features

  • • Real-time race schedule and results tracking
  • • Driver and constructor standings overview
  • • Clean and responsive mobile UI
  • • Firebase integration for dynamic data handling

Result

This project enhanced my understanding of mobile app development and real-time data integration. It also improved my ability to design user-friendly interfaces and manage application flow effectively.
